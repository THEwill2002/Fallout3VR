# Fallout3VR — guide français

Mod VR expérimental pour Fallout 3 sur PC : suivi du casque en 6DoF, manettes suivies, locomotion, menus sur panneau et miroir pour filmer.

**Pré-alpha privée. Aucun téléchargement public n'est encore disponible.** Les lanceurs actuels dépendent encore du dossier de développement. La préparation de cette page ne signifie pas que l'alpha est publiée.

## État testé

Configuration de développement : Steam, exécutable Fallout 3 1.7.0.4 exact, Quest 3, Virtual Desktop, RTX 4070. Link et les autres configurations restent à valider. Le patch Intel utilisé sur cette installation est conservé, mais n'est pas fourni.

Le suivi des mains démarre automatiquement. Les menus et le déplacement de la carte ont été confirmés par le testeur. Le zoom de la version 0.64 a été confirmé fonctionnel dans le casque le 1 octobre 2026.

## Commandes utiles

- Joystick gauche : marcher. Joystick droit : tourner.
- Gâchette droite : tirer. A : interagir avec l'objet regardé.
- X : recharger ; Y : Pip-Boy ; B : sauter.
- Prise droite maintenue puis B : pause ; refaire la combinaison pour revenir.
- Les deux prises maintenues une seconde : recentrage.
- Prise gauche près d'une arme compatible : prise à deux mains.
- Dans le Pip-Boy : X change Stats/Items/Data, A ou gâchette droite valide.
- Carte : joystick droit pour le curseur, gâchette gauche maintenue pour glisser depuis une zone vide.
- Zoom : prise gauche + joystick gauche haut/bas, après retour du joystick au centre.
- Ctrl+T : rotation fluide ou par crans. Ctrl+U : afficher/masquer le HUD.

## Limites à connaître

Les images sont alternées entre les yeux. Le déplacement est à huit directions. La prise à deux mains est validée principalement sur le BB gun ; le mode universel reste expérimental. Les swings automatiques sont réservés au bâton de police et déclenchent une attaque native, sans simulation complète de collision de l'arme.

UHD désigne ici le transport 1536 × 1536 par œil, pas une promesse de résolution native ou de performances identiques sur tous les PC.

Avant publication : installation portable, vérification des licences et des fichiers distribués, puis essai d'installation sur une autre machine. Ne pas publier les captures de maillages, sauvegardes ou fichiers du jeu.
