# Testing and bug reports

The first alpha download is still awaiting final launcher validation. Feedback forms are already available in [GitHub Issues](https://github.com/THEwill2002/Fallout3VR/issues/new/choose). A GitHub account is needed to submit a report. French and English are welcome.

- Choose **Bug report** for a reproducible defect. Search existing issues first and add evidence to a matching report instead of opening a duplicate.
- Choose **Alpha feedback** for a successful compatibility test, performance observations, or a feature suggestion. Successful launch, gameplay, and normal shutdown reports on another PC are especially useful.

Use the issue comments for follow-up test results and questions so the full discussion stays with the report. No separate Discord account is needed.

Report one issue at a time. Include the build/profile, game executable version, headset, OpenXR runtime, GPU, reproducible steps, expected behaviour, and observed behaviour. For rendering issues, say whether the defect persists with one eye closed. For controller issues, verify both controllers in the runtime dashboard first.

Screenshots or short clips are useful when they show the defect. Review them for private information before uploading. Do not attach saves, executables, BSA/ESM archives, Intel patch binaries, raw mesh/shader captures, or complete unreviewed logs. A short relevant log excerpt with personal paths removed is sufficient initially.

Source contribution and build instructions will follow the code-license decision and preparation of a clean source package. This preview is documentation, not a complete buildable repository.
